# About this copy

This is a public copy of Team T242's working repository for Project Huntsman
(QUT IFB398, 2026 Semester 2), shared so the QUT teaching team can open the
outputs linked from our Phase 1 report without needing an account.

V Source Development's design files are not included: the Inventor CAD, the
part-weight sheet, photos and videos of the robot, and the simulation geometry
generated from the CAD (`simulation/mujoco/meshes`, `spider*.xml`,
`cad/huntsman_cad.json`). They were removed from the whole history. All of the
team's code, tests, documentation and history are otherwise unchanged, so the
simulation builds only where the partner files are present (our private
working repository, which V Source can access).

Automated checks are turned off in this copy because they need the partner
files to build the robot. They run on every change in the working repository.
