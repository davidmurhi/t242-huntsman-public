# T242 — Project Huntsman
**IFB398 IT Capstone Phase 1 | QUT 2026 Semester 2**

## Project Overview
Project Huntsman is a multi-terrain autonomous robot platform developed by V Source Development, designed for deployment in post-disaster search and rescue environments. This repository contains the software developed by Team T242 as part of the QUT IT Capstone program.

Our focus is on the walking gait control system — using machine learning to teach a legged platform to move reliably across unpredictable terrain such as rubble, mud and uneven ground.
